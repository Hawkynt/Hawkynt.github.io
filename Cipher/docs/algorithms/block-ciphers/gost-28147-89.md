# GOST 28147-89

> Educational implementation of the Soviet/Russian GOST 28147-89 block cipher (Magma). 64-bit Feistel network with 256-bit keys using the TestParam S-box set.

## Security

**Status:** 🎓 Educational Only

### Known vulnerabilities

| Issue | Description | Mitigation |
| --- | --- | --- |
| Weak key classes | Some keys may exhibit weak differential properties and reduced cycle lengths. | Use uniformly random keys and avoid structured key material. |
| S-box dependency | Security depends heavily on the selected S-box set. | Use standardized or audited S-box collections (e.g., TestParam, CryptoPro). |
