# Cartman-2X (DarkCrypt)

> Block cipher from the DarkCrypt Total Commander plugin. 1024-bit key, 128-bit block. The key seeds 64 key-dependent derangement S-boxes (generated by running the cipher in OFB mode over a fixed bootstrap S-box) plus small index/rotation tables driving an 8x8-iteration substitution/ARX round function.
