# FNAm2-512 (DarkCrypt)

> FNAm2-512 block cipher from the DarkCrypt Total Commander plugin. A 128-bit-block / 512-bit-key ARX-with-multiply construction: 64 sequential steps mix the four little-endian words using key-derived subkeys built from 32-bit multiplication.
