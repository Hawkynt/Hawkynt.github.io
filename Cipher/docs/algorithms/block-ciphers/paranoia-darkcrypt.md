# Paranoia (DarkCrypt)

> Undocumented 256-bit block cipher from the DarkCrypt Total Commander plugin: an 8-word generalized Feistel network over a 512-bit key, whose 48-round subkey table and 16-word whitening table are both generated by a 144-iteration, six-tap additive lagged-Fibonacci generator seeded from the key. No public specification is known.
