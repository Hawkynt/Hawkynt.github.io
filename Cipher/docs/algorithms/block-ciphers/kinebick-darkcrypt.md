# Kinebick (DarkCrypt)

> 128-bit block, 512-bit key cipher from the DarkCrypt Total Commander plugin. Unrolled ARX network with three boolean mixers over four 32-bit words, RC6-style plus RC4-style key schedule driven by a fixed 64x256 substitution table.
