# KDF1-ISO-18033

> KDF1 Key Derivation Function from ISO/IEC 18033-2. Counter-based iterative hash KDF supporting arbitrary output lengths with 32-bit counter starting at 0.

## Security

**Status:** 🎓 Educational Only

### Known vulnerabilities

| Issue | Description | Mitigation |
| --- | --- | --- |
| Counter Overflow | KDF1-ISO-18033 uses 32-bit counter; output limited to 2^32 hash blocks (theoretical max ~80GB for SHA-1) | — |
| Hash Function Strength | Security depends on hash function choice. SHA-1 is considered weak; use SHA-256 or stronger | — |
| Counter Starts at Zero | Unlike KDF2 which starts at 1, KDF1-ISO-18033 counter starts at 0. This is intentional per ISO spec | — |
