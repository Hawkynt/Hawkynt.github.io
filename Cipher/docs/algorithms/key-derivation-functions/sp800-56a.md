# SP800-56A

> NIST SP 800-56A Revision 3 single-step key derivation function for key agreement schemes. Uses concatenation format: counter || Z || FixedInfo with hash or HMAC-based derivation.

## Properties

| Property | Value |
| --- | --- |
| Category | Key Derivation Functions |
| Sub-category | Key Agreement KDF |
| Security status | 🛡️ Secure |
| Complexity | Intermediate |
| Inventor | National Institute of Standards and Technology (NIST) |
| Year | 2018 |
| Origin | 🇺🇸 United States |
| Source | [`algorithms/kdf/sp800-56a.js`](../../../algorithms/kdf/sp800-56a.js) |

## Parameters

| Parameter | Supported values |
| --- | --- |
| Output sizes | 1 byte (8 bits) to 8191 bytes (65528 bits) |

| Flag | Value |
| --- | --- |

## Security

**Status:** 🛡️ Secure

### Known vulnerabilities

| Issue | Description | Mitigation |
| --- | --- | --- |
| Weak Hash Function | Avoid SHA-1 for cryptographic security; use SHA-256 or stronger hash functions | — |
| Insufficient Shared Secret Entropy | Ensure shared secret Z has sufficient entropy from secure key agreement | — |
