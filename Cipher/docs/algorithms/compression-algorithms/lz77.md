# LZ77

> Dictionary-based compression using sliding window technique. Encodes data as a flat, self-describing stream of literal/match tokens (1 flag byte, then either a raw byte or a little-endian distance+length pair) found via a hash-chain match finder over a sliding history buffer. Foundation for many modern compression formats like DEFLATE.
