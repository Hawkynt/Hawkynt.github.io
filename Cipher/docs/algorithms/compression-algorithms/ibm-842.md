# IBM 842

> Fixed-block dictionary compression built for IBM POWER hardware accelerators. Encodes data in 8-byte chunks as a template opcode selecting a mix of literal bytes and back-references into 2/4/8-byte ring-buffer dictionaries. This implementation covers the eight core chunk templates plus end-of-stream and padded-tail handling.
