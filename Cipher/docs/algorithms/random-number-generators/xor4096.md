# XOR4096

> XOR4096 is an extremely long-period pseudo-random number generator from Richard P. Brent's xorgens collection. With a 4096-bit state and period of 2^4096-1, it uses optimized shift parameters (10,5,26) discovered through exhaustive computer search. Fast, high-quality, and passes all known statistical tests.
