# GFSR

> Generalized Feedback Shift Register is a shift-register-based PRNG using multiple feedback taps for long-period pseudo-random sequences. This gfsr4 variant uses a 521-word state with four-tap XOR recurrence, providing period 2^16672 and excellent statistical properties for simulations.
