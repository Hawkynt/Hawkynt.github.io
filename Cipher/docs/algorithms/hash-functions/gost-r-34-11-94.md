# GOST R 34.11-94

> Soviet/Russian national hash standard producing 256-bit digests. Uses GOST 28147-89 cipher internally with D-A S-box. Superseded by Streebog (GOST R 34.11-2012).

## Security

**Status:** ⚠️ Deprecated

### Known vulnerabilities

| Issue | Description | Mitigation |
| --- | --- | --- |
| Deprecated standard | GOST R 34.11-94 has been superseded by Streebog (GOST R 34.11-2012) since 2012. | Use Streebog for new applications requiring Russian cryptographic standards. |
| Collision resistance | Theoretical attacks on collision resistance exist, though no practical collisions are known. | Consider this algorithm for legacy compatibility only, not for new security applications. |
