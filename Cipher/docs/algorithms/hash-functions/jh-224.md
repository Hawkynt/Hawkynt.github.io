# JH-224

> JH is a SHA-3 finalist designed by Hongjun Wu. A 1024-bit state is regrouped into 256 four-bit elements and driven through 42 rounds of S-box substitution, a maximum distance separable mixing layer and a permutation. This is the 224-bit variant of the round-three design.

## Security

**Status:** not classified — treat as unverified.

### Known vulnerabilities

| Issue | Description | Mitigation |
| --- | --- | --- |
| Preimage attacks on reduced rounds | Preimage and semi-free-start results exist against JH cut down to a fraction of its 42 rounds. The full function has no published break, but SHA-3 went to Keccak instead. | — |
