# SHA-3-384

> SHA-3-384 produces 384-bit digests using the Keccak sponge construction with capacity 768 bits. Part of the NIST FIPS 202 standard.

| Property | Value |
| --- | --- |
| Category | Hash Functions |

| Variant | 384 |
| Security status | Not classified |

| Year | 2015 |
