# SHA-3-224

> SHA-3-224 produces 224-bit digests using the Keccak sponge construction with capacity 448 bits. Part of the NIST FIPS 202 standard.

## Properties

| Property | Value |
| --- | --- |
| Category | Hash Functions |

| Variant | 224 |
| Security status | Not classified |
| Complexity | Intermediate |
| Inventor | Guido Bertoni, Joan Daemen, Michaël Peeters, Gilles Van Assche |
| Year | 2015 |
| Origin | 🇧🇪 Belgium |
