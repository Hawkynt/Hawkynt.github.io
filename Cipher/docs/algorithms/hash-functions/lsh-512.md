# LSH-512

> Korean cryptographic hash function standard producing 512-bit digests. Designed by KISA with 28-step compression function and 64-bit operations.

## Properties

| Property | Value |
| --- | --- |
| Category | Hash Functions |
| Sub-category | LSH Family |
| Security status | Not classified |
| Complexity | Advanced |
| Inventor | Korea Internet&Security Agency (KISA) |
| Year | 2015 |
| Origin | 🇰🇷 South Korea |
| Source | [`algorithms/hash/lsh.js`](../../../algorithms/hash/lsh.js) |

## Parameters

| Parameter | Supported values |
| --- | --- |
| Hash sizes | 64 bytes (512 bits) |

## Security

**Status:** not classified — treat as unverified.

No vulnerabilities are recorded for this implementation.
