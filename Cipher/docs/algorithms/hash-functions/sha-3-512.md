# SHA-3-512

> SHA-3-512 produces 512-bit digests using the Keccak sponge construction with capacity 1024 bits. Part of the NIST FIPS 202 standard.

## Properties

| Property | Value |
| --- | --- |
| Category | Hash Functions |
| Sub-category | SHA-3 Family |
| Variant | 512 |
| Security status | Not classified |
| Complexity | Intermediate |
| Inventor | Guido Bertoni, Joan Daemen, Michaël Peeters, Gilles Van Assche |
| Year | 2015 |
| Origin | 🇧🇪 Belgium |
| Source | [`algorithms/hash/sha3.js`](../../../algorithms/hash/sha3.js) |
