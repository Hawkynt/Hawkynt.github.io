# Wozencraft Ensemble

> Set of linear codes where most codes satisfy Gilbert-Varshamov bound. Named after John Wozencraft. Used as inner codes in Justesen code construction. Ensemble consists of all [n,k] linear codes generated by random generator matrices. With high probability, randomly chosen code from ensemble is good.
