# GOST 28147-89 MAC

> CBC-MAC construction using GOST 28147-89 block cipher. Specified in GOST R 34.13-2015 for message authentication.

## Security

**Status:** ⚠️ Deprecated

### Known vulnerabilities

| Issue | Description | Mitigation |
| --- | --- | --- |
| Deprecated standard | GOST 28147-89 has been superseded by newer Russian standards (Kuznyechik/Magma). | Use modern MAC algorithms like CMAC with AES or HMAC-SHA256 for new applications. |
| S-box dependency | Security depends on the selected S-box parameter set. | Always use standardized S-box sets (E-A, CryptoPro, etc.). |
