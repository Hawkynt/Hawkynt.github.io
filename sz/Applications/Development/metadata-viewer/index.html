Metadata Viewer - File Analysis and Metadata Editor

Identify file types via magic bytes, parse format-specific metadata structures, display embedded images, compute hashes and checksums, and edit metadata fields. Supports 30+ file formats with 29 hash/checksum algorithms including MD5, SHA-1, SHA-256, SHA-512, SHA-3, BLAKE2, BLAKE3, CRC32, and more.

Features

  • File type identification via magic bytes and header analysis
  • Format-specific metadata parsing for images, audio, video, documents, archives, and executables
  • 29 hash and checksum algorithms: MD5, SHA-1, SHA-256, SHA-512, SHA-3, BLAKE2, BLAKE3, RIPEMD, Whirlpool, Tiger, CRC, Adler, Fletcher
  • Supports JPEG, PNG, GIF, BMP, WebP, AVIF, TIFF, SVG, TGA, PCX, DDS image formats
  • Audio format support: MP3 (with Xing/LAME/VBRI), FLAC, WAV, OGG, Opus, MIDI, AIFF, AAC
  • Video codec analysis: H.264, H.265, VP8, VP9, AV1 with SPS parsing
  • Archive inspection: ZIP, TAR, RAR, 7z, ARJ, LZH, CAB, and 40+ archive formats
  • Executable analysis: PE, ELF, Mach-O, APK, Java .class files
  • Disassembly support: x86, ARM, Java bytecode, MSIL, PowerPC, Dalvik, 6502, Z80, M68K
  • Embedded image preview and extraction
  • Metadata field editing and export
