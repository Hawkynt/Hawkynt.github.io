About Data Encryption

Data Encryption - SZ Desktop Encryptor

A text encryption and decryption utility for the SynthelicZ desktop. Encrypts text of any language with AES-256-GCM under a passphrase and decrypts it back, entirely in the browser.

Features

  • AES-256-GCM encryption with a PBKDF2-SHA-256 key from your passphrase
  • Unicode text in, compact base64 text out
  • Tamper detection and clear messages for a wrong key or damaged text
  • Decrypts text from the earlier XOR version
  • Key validation with visual feedback for empty key attempts
  • Clipboard integration to copy output text
  • Swap input and output for efficient encrypt/decrypt round-trips
  • Clear all fields with one click
